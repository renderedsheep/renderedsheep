## Innovation manager who builds

#### Git-hosted Projects

| | |
|---|---|
|💰 **Commercialization Workbench** · [try it!](https://commercializationworkbench.com) | A free, private self-assessment that shows founders and researchers what could stop their technology from being adopted, what evidence they have, and what to test next. Brings together frameworks usually taught separately: Adoption Readiness Levels, I-Corps customer discovery, the Business Model Canvas and TRIZ. Runs entirely in the browser, with PDF and Excel reports and a Cohort View for cohort managers. JavaScript, Python. Beta is live; source code coming here after initial testing. |
|☢️ **[SKALA Simulator](https://github.com/renderedsheep/skala-simulator)** · [try it!](https://renderedsheep.github.io/skala-simulator/) | A browser reconstruction of SKALA, the process computer at Chernobyl Unit 4, running on the nuclear reactor's real control-rod map. Built from and checked against the IAEA's INSAG-7 report, Nikolai Karpan's book and the surviving recorder logs. JavaScript, Python. |
|✈️ **[R/C MiG-21 Flight Stabilizer](https://github.com/renderedsheep/mig21-flight-stabilizer)** | A DIY gyro stabilizer for a 1:10 scale R/C MiG-21 jet fitted with an electric ducted fan (EDF), built on an ESP32 and an MPU-6050 motion sensor. C++. VERY much a work in progress. |
|🎮 **[PlayStation Serial Utility](https://github.com/renderedsheep/PlayStation-Serial-Utility)** | Sends compiled homebrew from a PC directly into a PS1's memory over a cheap USB-to-serial cable, so code can be tested on real hardware without burning discs. PSXSERIAL-compatible. Python. |
|🕹️ **[Sega Genesis BMP2HEX](https://github.com/renderedsheep/SegaGenesis-BMP2HEX)** | Converts bitmaps into Sega Genesis-ready tile and palette data (16-color palettes, 8x8 tiles, 9-bit color). Built for *Miracle on Ice*, an NHL 94 mod. Python. |
|🌐 **[ESP Network Monitor](https://github.com/renderedsheep/ESP-Network-Monitor)** | An ESP32 panel that monitors up to nine devices or servers on a network, one LED each. Green means up and running; red indicates two missed checks. C++. |
