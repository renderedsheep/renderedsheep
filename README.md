## Hi there 🖖

### Indie developer, filmmaker and innovation program manager

My work sits where technology meets other fields: AI, film and visual effects, data visualization and energy research. By day I manage innovation programs, running an AI startup support program and helping university faculty commercialize their research. #### Projects

| | |
|---|---|
|☢️ **[SKALA simulator](https://github.com/renderedsheep/skala-simulator)** · [try it](https://renderedsheep.github.io/skala-simulator/) | A browser reconstruction of SKALA, the process computer at Chernobyl Unit 4, running on the reactor's real control-rod map. Built from and checked against the IAEA's INSAG-7 report, Nikolai Karpan's book and the surviving recorder logs. JavaScript, Python. |
|✈️ **[R/C MiG-21 Flight Stabilizer](https://github.com/renderedsheep/mig21-flight-stabilizer)** | A DIY gyro stabilizer for a 1:10 scale R/C MiG-21 jet with a ducted fan, built on an ESP32 and an MPU-6050 motion sensor. C++. |
|🎮 **[PlayStation Serial Utility](https://github.com/renderedsheep/PlayStation-Serial-Utility)** | Sends compiled homebrew from a PC directly into a PS1's memory over a cheap USB-to-serial cable, so code can be tested on real hardware without burning discs. PSXSERIAL-compatible. Python. Work in progress. |
|🕹️ **[Sega Genesis BMP2HEX](https://github.com/renderedsheep/SegaGenesis-BMP2HEX)** | Converts bitmaps into Genesis-ready tile and palette data (16-color palettes, 8x8 tiles, 9-bit color). Written for *Miracle on Ice*, an NHL 94 mod. Python. |
|🌐 **[ESP Network Monitor](https://github.com/renderedsheep/ESP-Network-Monitor)** | An ESP32 box that monitors up to nine devices on a home network, one LED each. Green means up; red means two missed checks. C++. |
